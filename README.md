# 💡 당뇨병 위험도 예측 시뮬레이션

> **2025 보건 탐구 프로젝트**  
> **기술 스택:** Python, Streamlit, Scikit-learn, Pandas  
> **핵심 주제:** 인공지능 머신러닝을 활용한 보건 지표 분석 및 성별 제약(임신 변수)을 제거한 일반화 당뇨병 위험도 예측 Web App

---

## 📌 프로젝트 배경 및 목적 (Overview)

### 1. 왜 '피마 인디언 데이터셋'인가?

* **절약 유전자(Thrifty Gene)와 급격한 식생활 변화**: 
  피마 인디언은 원래 사막 지대의 척박한 환경에 적응하며 '음식을 몸에 축적하는 절약 유전자'를 발달시킨 부족이었습니다. 그러나 미국 이주 후 단 **50년 만에 서구화된 고칼로리 식단**을 접하면서, 못 먹는 상황에 유리했던 유전자가 비만과 당뇨병을 초래하는 결과를 낳았습니다.
* **세계 최고 수준의 당뇨병 발병률**: 
  현재 피마 인디언은 남성의 63%, 여성의 70%가 당뇨병에 시달릴 정도로 세계에서 당뇨병 발병률이 가장 높은 집단 중 하나입니다.
* **후성유전학(Epigenetics)과 세대 간 영향의 대표 사례**: 
  식습관 변화로 인해 렙틴(포만감 조절 호르몬) 생성 유전자 등의 발현(메틸화)이 변하고, 이것이 자손(3대)에게까지 영향을 미친 보건학적으로 매우 중요한 연구 대상입니다.
* **AI·의학 분야의 표준 벤치마크**: 
  미국 국립 보건원(NIDDK)이 수집한 이 데이터는 당뇨병 예측 머신러닝 모델을 검증할 때 **가장 표준적이고 대표적으로 사용되는 데이터셋**입니다.

---

### 2. 프로젝트의 문제 의식 및 개선 방향

기존 피마 인디언 데이터셋은 연구 대상이 여성으로 한정되어 있어 **`Pregnancies`(임신 횟수)** 변수를 포함하고 있었습니다. 이로 인해 남성이나 임신 경험이 없는 사람에게는 모델을 적용할 수 없는 **성별 편향** 및 **적용 한계**가 존재했습니다.

특히, 서구화된 식습관으로 인해 비만 및 성인병 인구가 증가하는 현대 사회에서는 **성별과 무관하게 누구나 자신의 위험도를 측정할 수 있는 일반화 모델**이 필요합니다.

본 프로젝트에서는 보건 탐구의 일환으로 **'임신 횟수' 변수를 제외**하고, 남녀노소 누구나 적용 가능한 **7가지 보편적 생체 지표**만을 활용하여 당뇨병 발병 위험도를 예측하는 머신러닝 모델을 구축했습니다.

## 📊 입력 생체 지표 (Features)

| 지표명 (Feature) | 설명 | 입력 범위 |
| :--- | :--- | :--- |
| **혈당 수치 (Glucose)** | 공복 혈당 농도 | 50 ~ 200 mg/dL |
| **혈압 (Blood Pressure)** | 이완기 혈압 | 30 ~ 130 mmHg |
| **피하지방 두께 (SkinThickness)** | 삼두근 피부 주름 두께 | 0 ~ 100 mm |
| **인슐린 수치 (Insulin)** | 혈청 인슐린 농도 | 0 ~ 900 mu U/ml |
| **BMI** | 체질량 지수 (체중 / 키²) | 10.0 ~ 60.0 |
| **당뇨 유전 영향도 (DPF)** | 당뇨병 내력 적응도 함수 | 0.0 ~ 2.5 |
| **나이 (Age)** | 만 나이 | 10 ~ 100세 |
